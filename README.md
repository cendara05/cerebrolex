# CerebroLex — Descargas

La aplicación de escritorio del abogado panameño: casos, plazos, documentos, honorarios y fondos de clientes en un solo
lugar, con Claude trabajando a tu lado y normas verificadas en fuente oficial.

**Sitio:** <https://cerebrolex.com> · **Contacto:** contacto@cerebrolex.com

## Descargar

| | Windows |
|---|---|
| **Probar 30 días gratis** (una bóveda, hasta 3 casos) | [CerebroLex-Prueba-Windows.exe](https://github.com/cendara05/cerebrolex/releases/latest/download/CerebroLex-Prueba-Windows.exe) |
| **Versión Pro** (se activa con tu clave de licencia) | [CerebroLex-Pro-Windows.exe](https://github.com/cendara05/cerebrolex/releases/latest/download/CerebroLex-Pro-Windows.exe) |
| Mac | muy pronto |

Después de instalarlo, **CerebroLex se actualiza solo** desde aquí.

Si Windows muestra «Windows protegió su PC», pulsa **Más información › Ejecutar de todas formas**: el instalador es
de CONECTIA PANAMA S.A. (estamos tramitando la firma de editor para que el aviso desaparezca).

## Requisitos

- Windows 10 u 11 (64 bits) · unos 600 MB de espacio
- Internet para activar y para trabajar con Claude
- Cuenta de Claude (Anthropic), plan Pro o superior, con Claude Code

## Qué hace

- 🏠 **Panel del despacho**: lo que vence esta semana, lo que falta facturar y cobrar, cumplimiento y pendientes.
- 📁 **Casos y clientes** con ficha, documentos, wiki y bitácora; ⚖️ **conflicto de intereses** al abrir cada caso.
- 🧮 **Términos** en días hábiles con feriados nacionales y distritales, alertas y resumen diario por WhatsApp.
- 🤖 **Claude integrado** (chat, consola, dictado por voz) y 🔎 **control de lo que redacta la IA** con verificación de citas.
- 📱 **WhatsApp** con menú por números para trabajar desde la calle.
- 📝 **Escritos desde plantillas**, ✍️ **firma electrónica** PAdES con tu certificado, 📨 **informe al cliente**.
- 📄 **Hoja de encargo** con consentimiento de la Ley 81 · 🛡 **debida diligencia** de la Ley 23.
- 💰 **Fondos de clientes** con rendición de cuentas · ⏱ **cronómetro** y facturación.
- ✉️ **Correo al expediente** · 🛟 **respaldo cifrado** fuera del NAS · 👥 **equipo y permisos**.
- 🧩 **Plugins** firmados y aislados, con tienda y clave propia; el primero: 🧮 **liquidación laboral**.
